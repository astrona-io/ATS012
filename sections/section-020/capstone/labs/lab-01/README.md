# PolicyExceptions Integration Capstone

Welcome to the Section 020 Capstone. This challenge runs a governed exception process end to end: the feature enabled and scoped, hygiene enforced on the exceptions themselves, one exemption that works and is auditable, and one that provably does nothing because it was filed in the wrong place.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS012.git -c sections/section-020/capstone/labs/lab-01
```
