# Narrow & Governed Exceptions Sandbox

Welcome to the Module 2 targeted practice sandbox. PolicyExceptions are already enabled and scoped to `platform-ns`. Your job is to make an exemption that is as narrow as the problem — each workload must opt in for itself — and to stop anyone writing an undocumented exception in the first place.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS012.git -c sections/section-020/module-02/labs/lab-01
```
