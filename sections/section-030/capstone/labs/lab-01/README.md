# Kyverno Metrics Integration Capstone

Welcome to the Section 030 Capstone. Two namespaces, one policy, identical enforcement — and a metrics configuration that measures one of them in full detail and the other not at all. This challenge asks you to configure that, then prove every part of it from the raw endpoint.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS012.git -c sections/section-030/capstone/labs/lab-01
```
