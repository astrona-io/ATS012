# Policy Testing Capstone

Welcome to the Section 040 Capstone. Two policies, two Pods and no cluster: you write the test file that pins what both policies must do, and a runner a pipeline can call. The test must also catch a wrong change to the mutate policy.

> UNTESTED: this lab was built and checked statically only. It has not been run with `astrona test`.

## Launching the Lab
```bash
astrona run --git git@github.com:astrona-io/ATS012.git -c sections/section-040/capstone/labs/lab-01
```
