# Write a Policy Test

Graded lab for the module on testing policies with the Kyverno CLI. You run a policy on two Pods, then write the `kyverno-test.yaml` that states the expected results. The task is in `question.md`; the walkthrough is in `solution.md`.

> UNTESTED: this lab was built and checked statically only. It has not been run with `astrona test`.

## Launching the Lab

```bash
astrona run --git git@github.com:astrona-io/ATS012.git -c sections/section-040/module-01/labs/lab-01
```

When you think you have finished, send it for grading:

```bash
astrona submit --git git@github.com:astrona-io/ATS012.git -c sections/section-040/module-01/labs/lab-01
```
