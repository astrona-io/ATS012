# Reading PolicyReports Sandbox

Welcome to the Module 1 targeted practice sandbox. In this lab you'll put two `Audit`-mode policies live — one scored, one advisory — create a compliant and a non-compliant Pod, and prove you can find and read the `PolicyReport` each one produced.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS012.git -c sections/section-010/module-01/labs/lab-01
```
