# Policy Reports Integration Capstone

Welcome to the Section 010 Capstone. This challenge combines everything the section covered: reading reports correctly, distinguishing scored from advisory findings, tuning the background scan so pre-existing workloads are actually seen, and proving you understand which policies a background scan will never evaluate.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS012.git -c sections/section-010/capstone/labs/lab-01
```
